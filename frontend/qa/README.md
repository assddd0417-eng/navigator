# 화면 흐름 점검 (가짜 서버)

백엔드·DB 없이 4개 역할의 화면 이동과 권한 표시를 브라우저로 점검한다. `/api/*` 요청을 `mock.cjs` 가 대신 답한다 (권한 403 만 흉내, 실제 업무 규칙은 아님).

```bash
cd frontend
npm run dev -- --port 5173          # 다른 터미널에서
node qa/flow_check.cjs              # Playwright 필요. 결과: PASS n / n, 화면은 qa/shots/
```

점검 내용: 로그인 전 깊은 링크 → 로그인 → 원래 화면, 권한 없는 화면 직접 입력, 사용자 바꾸기 때 머물기/이동, 새로고침·뒤로가기 때 고른 항목 유지, 추천 검토·최종 결정 권한, 문서 → 성과카드 → 발행, 갭 확정·기각, 잘못된 주소, 휴대폰 폭.
