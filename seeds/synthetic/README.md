# 검증용 합성 데이터 (공개 사례 기반)

국기연은 실제 이어달리기 사례 자료를 제공할 수 없어서, **공개 자료에서 뼈대를 가져와 합성한 데이터**로 추천 적중률을 잰다.

- `build_corpus.py`: 생성기. `corpus.json` 은 이 파일로만 만든다 (`python seeds/synthetic/build_corpus.py`).
- `corpus.json`: 과제 60개 (공개 사례 기반 25 + 헷갈리는 오답 35), 결과보고서, 성과카드, 기획수요 15개, 정답 연계 17쌍.

## 무엇이 진짜이고 무엇이 합성인가

| 구분 | 내용 |
|---|---|
| 공개 자료에서 가져온 것 | 사업명, 품목, 무기체계, 일부 수치. 예: 천마 부품국산화 416억 원·9종, 22-3차 부품국산화 과제명, AESA TR 모듈 약 1,000개, 터보샤프트엔진 가스발생기 패키지 (각 과제 `sources`, `public_facts`) |
| 합성한 것 | 결과보고서 본문, 시험 수치 대부분, 미해결 항목, 기획수요, **선행→후속 연계(정답)**. 공개 자료에는 연계 정보가 거의 없음 |
| 실제 공개된 연계 흐름 | 터보샤프트엔진 (무인기 터보팬 → 가스발생기 → 동력터빈·기어박스 후속), AESA 레이더 (TR 모듈 집적 → 국산 소자) |

- 기업명은 모두 `(가상)` 이 붙은 가상 기업이다.
- 기획수요의 요구성능 지표명은 정답 카드와 일부러 다르게 썼다. 같으면 지표명 일치만으로 정답이 1위가 되어 적중률이 부풀려진다 (`tests/test_synthetic_corpus.py` 가 검사).
- 오답 과제 35개는 정답과 분야·용어가 겹치게 만들었다 (예: 회전결합기 ↔ 안테나 구동 모터·슬립링).

## 실행

```bash
cd backend
python -m app.synthetic all     # 적재 + 측정 (load / eval 따로도 가능, 재실행 안전)
```

결과는 `eval_run` 에 기록되고 KPI 화면의 평가 지표(`/kpi/eval`)에 나온다.
**적중률은 `EMBEDDER=bge_m3` 로 잰 값만 의미가 있다.** 합성 데이터 점수는 "이 방식이 작동한다"는 근거이고 실제 성능을 보장하지 않는다.
